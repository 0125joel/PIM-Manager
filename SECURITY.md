# Security Policy

## Reporting a vulnerability

Please do not open a public GitHub issue for a security problem.

Send the report by email to **joel@prins.in** with the subject `PIM Manager security`. Include:

- a description of the problem and its impact
- the steps to reproduce it, and the version you use
- what you have already tried, if anything

Please give a reasonable time to fix the problem before you publish anything about it.

## Supported versions

Security fixes go into the latest release. Older versions are not patched; update to the latest release.
